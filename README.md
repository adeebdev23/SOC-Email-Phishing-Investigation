
# SOC Email Phishing Investigation Portfolio

A collection of five hands-on email security investigations
using real-world phishing samples.

## Investigation Labs

| Case | Investigation | Focus |
|---|---|---|
| 01 | [Microsoft Account Impersonation](cases/01-Microsoft-Account-Impersonation/README.md) | Header analysis, reply lure, tracking pixel |
| 02 | [Chase Banking Phishing](cases/02-Chase-Banking-Phishing/README.md) | Banking impersonation and phishing URLs |
| 03 | [Fake Order Confirmation](cases/03-Fake-Order-Confirmation/README.md) | Order fraud and deceptive content |
| 04 | [MetaMask QR Phishing](cases/04-MetaMask-QR-Phishing/README.md) | QR code analysis and wallet impersonation |
| 05 | [Advance-Fee Scam](cases/05-Advance-Fee-Scam/README.md) | Social engineering and financial fraud |

## Investigation Methodology

1. Examine email headers and sender identity
2. Analyse SPF, DKIM and DMARC
3. Inspect email content and embedded indicators
4. Investigate relevant IOCs using threat intelligence
5. Correlate findings and determine a verdict
6. Document evidence and recommended SOC actions

## Tools

- VirusTotal
- AbuseIPDB
- Visual Studio Code
- Email Header Analysis
- Threat Intelligence Research

## Scope

Independent educational investigations using publicly
available email samples.

Findings and conclusions are documented separately
for each case. No production incident response
actions were performed.

Warning: Some source samples contain potentially
malicious URLs or embedded content. Do not open
links or execute attachments.
